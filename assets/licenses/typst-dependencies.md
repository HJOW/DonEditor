# Typst 지원으로 추가된 외부 Rust crate와 라이선스

Typst 지원(`typst`, `typst-layout`, `typst-pdf`, `typst-svg`, `typst-assets`)을 넣으면서 Cargo.lock 에 새로 들어온 외부 crate 입니다.
버전과 아카이브 SHA256 은 Cargo.lock 에 고정되어 있습니다. 라이선스 표현식은 각 crate 의 Cargo.toml 값입니다.
각 crate 의 저작권 고지와 라이선스 전문은 crates.io 소스 아카이브와 저장소에 있으며, Apache-2.0 계열은 `typst-LICENSE-APACHE` 와 같은 전문을 따릅니다.
