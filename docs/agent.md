## 패널 열기와 숨기기

Agent 패널의 기본 위치는 오른쪽입니다. 보기 메뉴의 Agent 패널 항목, 명령 팔레트의 `agent_panel::ToggleFocus`, 또는 도크의 Agent 아이콘으로 엽니다. 패널 위쪽 닫기 버튼으로 숨겨도 도크 아이콘은 남으며, 다시 클릭하면 패널을 열 수 있습니다. 도크 메뉴로 왼쪽 또는 오른쪽으로 옮길 수 있습니다.

## API 키 설정

1. **제공자** 버튼으로 OpenAI 또는 Anthropic을 선택합니다.
2. **모델 ID**에 자신의 API 계정에서 사용할 수 있는 모델을 입력합니다. 기본값은 변경할 수 있습니다.
3. API 키 입력란에 키를 넣고 **키 저장**을 누릅니다. Windows 자격 증명 관리자, macOS 키체인 또는 Linux Secret Service에 제공자별로 저장합니다.
4. 메시지를 입력하고 **보내기**를 누릅니다.

저장된 키가 없거나 OS 저장소를 읽을 수 없을 때는 `OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY` 환경 변수를 사용합니다. 환경 변수를 설정한 뒤 앱을 다시 시작해야 현재 프로세스에 반영됩니다. 키를 프로젝트 설정, 채팅 메시지, 저장소에 넣지 마세요. **키 삭제**는 선택한 제공자의 OS 저장 항목을 지우며 환경 변수는 변경하지 않습니다.

Linux에서 저장에 실패하면 데스크톱의 Secret Service가 실행 중이고 잠금 해제되어 있는지 확인하세요. 저장 실패를 평문 파일 저장으로 우회하지 않습니다.

## 컨텍스트와 도구 사용

**현재 컨텍스트 첨부**를 누르면 활성 파일의 텍스트·선택 범위와 열린 탭 정보를 다음 요청에 첨부합니다. 선택 영역만 있는 경우에도 현재 구현은 파일 전체 텍스트를 포함합니다. 첨부 상태를 확인하고 제공자에게 보내도 되는 파일인지 판단하세요.

Agent는 파일·탭 조회, 편집, 검색, 설정, 터미널과 일반 편집기 액션을 공용 도구로 사용할 수 있습니다. 읽기 도구는 결과를 바로 반환하며, 변경 작업은 편집기 안에 승인창을 띄웁니다. 텍스트 변경안의 이전/이후 내용을 확인한 다음 승인하거나 거절하세요. 편집 도구로 바꾼 버퍼는 자동 저장하지 않으며 저장은 별도 도구 또는 일반 저장 명령으로 수행합니다.

**중단**은 진행 중인 응답과 이후 도구 실행을 멈춥니다. 이미 승인되어 완료된 변경을 되돌리지는 않습니다. 한 응답에서 도구를 계속 호출할 수 있는 횟수에 제한이 있으므로, 한도 안내가 나오면 새 메시지로 이어갈 수 있습니다.

## 대화 기록과 오류

**새 대화**로 현재 대화를 정리하고 새로 시작합니다. **대화 기록**에서 이전 대화를 열 수 있으며 기록 삭제 기능으로 저장한 대화를 제거할 수 있습니다. 대화와 도구 결과는 앱의 로컬 데이터 DB에 저장되므로, 소스 코드나 민감한 정보를 포함했다면 [데이터 보관 안내](security.md)를 참고하세요. API 키 입력란의 값 자체는 대화 DB에 저장하지 않습니다.

인증 오류는 키와 모델 접근 권한을, 요청 한도 오류는 제공자의 한도·잔액을 확인합니다. 연결 오류는 네트워크 상태를 확인하고 다시 시도합니다. 오류를 공유할 때 키·토큰·개인 코드가 포함되지 않았는지 먼저 확인하세요. 실제 API 사용은 사용자의 제공자 계정으로 이루어집니다.
