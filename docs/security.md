# 도구 승인과 데이터 보관

[사용 안내 목차](index.md) · [Agent](agent.md) · [MCP](mcp.md)

## 읽기와 변경 승인

Agent와 MCP는 같은 편집기 도구를 사용합니다. 파일·탭·버퍼·진단 등 읽기 도구는 별도 변경 승인 없이 정보를 반환합니다. MCP를 연결한 클라이언트는 이런 정보를 읽을 수 있으므로, 접근을 허용할 클라이언트에만 연결하세요. 사용자 설정 조회 결과에도 개인 설정이 들어갈 수 있습니다.

텍스트 변경은 이전/이후 내용을 보여 주는 승인창에서 확인합니다. 거절하거나 창을 닫으면 실행하지 않습니다. 승인 대기 중 파일이 바뀌었다면 덮어쓰지 않고 새 변경안을 요청하도록 오류를 반환합니다. 저장, 프로젝트 전체 치환, 터미널 실행, 설정 변경과 범용 액션도 승인 대상입니다. 여러 파일 편집은 수정된 버퍼로 남으므로 결과를 확인한 뒤 저장할 수 있습니다.

범용 액션은 편집기의 일반 동작을 호출하므로 추가 대화상자나 저장 확인을 띄울 수 있습니다. 터미널 명령은 실제 사용자 권한으로 실행되며 승인 전에 명령 내용을 확인해야 합니다. 중단은 앞으로의 작업을 멈추며 이미 실행된 작업을 취소하지는 않습니다.

## API 키

설정 > 에이전트의 키 저장(또는 키가 없을 때 Agent 패널에 나타나는 키 입력란)은 Windows 자격 증명 관리자, macOS 키체인 또는 Linux Secret Service에 제공자별로 저장합니다. 서비스 이름은 `DonEditor.Agent`입니다. 키를 평문 설정 파일이나 대화 DB에 따로 저장하지 않습니다. OS 저장소를 읽지 못하면 해당 제공자의 환경 변수를 확인합니다.

키 삭제는 OS 저장 항목을 지우며, 환경 변수에 남은 키는 사용자가 별도로 제거해야 합니다. 다른 앱이 환경 변수를 주입했다면 해당 앱 설정도 확인하세요. OS 저장소가 잠겼거나 사용할 수 없다면 오류를 해결한 뒤 다시 저장합니다.

## 제공자에게 전송하는 내용

메시지와 대화에 포함된 도구 결과를 선택한 OpenAI/Anthropic API(설정에서 API 서버 URL을 지정했다면 그 주소)로 보냅니다. 매 요청에는 열린 프로젝트 폴더 경로, 현재 파일과 열린 탭의 이름·경로가 자동으로 포함됩니다(파일 내용은 제외). 현재 컨텍스트 첨부는 파일 전체 텍스트, 선택 범위와 탭 정보를 포함할 수 있습니다. Agent가 읽기 도구로 얻은 내용도 후속 요청에 포함됩니다. 전송할 수 없는 회사 코드·개인정보·비밀이 있는 프로젝트에서는 요청과 연결 범위를 먼저 판단하세요. Don Editor가 각 제공자의 서버 측 보관 정책을 제어하지는 않습니다.

## 로컬 기록과 MCP 토큰

대화·도구 결과·비밀이 아닌 패널 설정은 Don Editor 데이터 DB에 저장합니다. 대화 기록 삭제 기능으로 앱이 보관한 기록을 지울 수 있으며, OS 백업·DB 백업·이미 전송한 제공자 기록까지 삭제하지는 않습니다. 데이터 폴더 위치는 [설치 안내](installation.md)에 있습니다.

MCP는 `127.0.0.1`에만 바인딩하고 무작위 Bearer 토큰을 사용합니다. 토큰은 앱 데이터 폴더의 `mcp/connection.json`에 기록하며 Unix 파일 권한 또는 Windows 사용자 ACL로 보호합니다. 서버를 끄거나 다시 시작하면 이전 토큰을 계속 사용할 수 없습니다. 같은 OS 사용자 권한을 가진 프로세스는 연결 파일에 접근할 수 있으므로, 로컬 실행이 별도의 OS 계정 격리를 대신하지는 않습니다.

문의나 오류 보고에는 API 키, MCP 토큰, 대화 원문 또는 개인 파일 내용을 그대로 첨부하지 마세요. 필요한 오류 메시지와 재현 절차에서 비밀 값을 지워 공유할 수 있습니다.
